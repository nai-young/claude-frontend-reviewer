# Claude Frontend Reviewer

AI tool that reviews React/Next.js components for accessibility, performance, maintainability and UX.

## Features

- Component audit with Claude
- Accessibility review
- Refactor suggestions
- Test suggestions
- GitHub Actions CI
- Claude Code instructions and Skills

## Claude Code integration

This repo includes:

- CLAUDE.md with project rules
- Custom Claude Skills
- GitHub Action for PR/issue automation

## What this project demonstrates

- Next.js App Router
- TypeScript
- Claude API
- Claude Skills
- Claude Code configuration
- AI-assisted code review
- GitHub Actions CI
- CodeRabbit integration
- Testing strategy
- Accessibility-first frontend development
